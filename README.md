# 🎷 Jazz on the Move

## 📌 Overview
**Jazz on the Move** is a premium online radio app designed for jazz music lovers. It offers a seamless streaming experience, curated playlists, and a rich selection of jazz from classic to contemporary styles. Whether you're working, relaxing, or exploring new jazz sounds, this app brings the best jazz to your fingertips.

## 🚀 Features
- 🎶 **Live Jazz Streaming** – Enjoy uninterrupted jazz radio 24/7.
- 🎵 **Curated Playlists** – Explore handpicked jazz selections across eras.
- ⭐ **Favorites & Custom Playlists** – Save and organize your favorite jazz tunes.
- 🎛️ **High-Quality Audio** – Experience clear, HD-quality jazz music.
- 🌙 **Dark Mode** – Enjoy a sleek, modern interface at any time of day.
- ⏳ **Sleep Timer** – Set a timer and drift off with smooth jazz.
- 🔄 **Background Playback** – Keep the music playing while multitasking.

## 🛠️ Development & Setup
### Prerequisites
- Flutter SDK
- Dart SDK
- Android Studio (for Android builds)
- Xcode & macOS (for iOS builds)

### Clone the Repository
```sh
   git clone https://github.com/yourusername/jazz-on-the-move.git
   cd jazz-on-the-move
```

### Install Dependencies
```sh
   flutter pub get
```

### Run the App
```sh
   flutter run
```

## 📦 Build Instructions
### Android APK
```sh
   flutter build apk
```

### iOS (Requires macOS & Xcode)
```sh
   flutter build ios
```
